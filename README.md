EMBERFALL — a top-down arena survival shooter. You are an ember wisp in a dark arena: dodge waves of Cinders, Spitters and Brutes, beat the Cinderlord boss every 5th wave, chain spark pickups for a combo up to ×8, and survive as long as you can. WASD to move, mouse to aim, click to shoot, Shift to dash. Synthesized WebAudio sound, particles, screen shake, and a best score that persists.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
